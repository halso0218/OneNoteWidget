# OneNoteWidget

Android ホーム画面用ウィジェットアプリ。1×1 サイズの小型ウィジェットを複数並べて使うことを想定しています。

## ウィジェット一覧

### AMeDAS（気象庁アメダス天気）
気象庁の AMeDAS API からリアルタイムの気象データを取得して表示します。

- 天気アイコン（絵文字）
- 気温（°C）
- 観測地点名
- AMeDAS 観測時刻

**設定項目**
- 観測地点（都道府県 → 地点スピナー、または現在地から最寄り地点を自動選択）
- 背景色・透明度
- 文字色
- 文字影のオン/オフ

### Clock（アナログ/デジタル時計）
Canvas 描画によるカスタム時計ウィジェットです。

**盤面スタイル（設定画面でサムネイル選択）**
- クラシック：12 個のドット目盛り付きアナログ
- シンプル：12・3・6・9 時の 4 点のみ
- ミニマル：目盛りなし、針のみ
- デジタル：時・分を 2 段表示（角丸背景）

**設定項目**
- 背景色・透明度
- 針・目盛り／数字の色

## 技術仕様

| 項目 | 内容 |
|---|---|
| 最小 SDK | API 26 (Android 8.0) |
| ターゲット SDK | API 35 |
| 言語 | Kotlin |
| 天気更新 | WorkManager（10 分間隔） |
| 時計更新 | AlarmManager（1 分間隔） |
| 天気 API | 気象庁 AMeDAS JSON API |
